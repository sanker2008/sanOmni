# sanKnow 开发知识库

## 定位

sanKnow 是 sanOmni 内的本地开发知识库。它不是替代代码编辑器或 AI 对话，而是把日常开发中会反复查找的原始资料保留下来：项目代码、设计文档、配置、已验证的处理结论，以及公开网页文档。

遇到报错、需要理解模块边界或准备修改旧功能时，先在 sanKnow 搜索关键词；结果会显示来源路径或 URL 和相关片段。确认上下文后，再打开完整来源或开始修改代码。

## 三类内容

### 项目索引

点击“添加项目”选择一个项目根目录，sanKnow 会在本机读取以下文件：

- 文档：`md`、`mdx`
- 代码：`rs`、`ts`、`tsx`、`js`、`jsx`、`mjs`、`cjs`、`css`、`scss`
- 配置：`json`、`toml`、`yml`、`yaml`

索引最多收录 2,000 个文件，单个文件最多 2 MiB，并跳过 `.git`、`node_modules`、`target`、`dist`、`build`、`coverage` 等依赖或生成目录。达到上限时会明确提示；之后更新索引只覆盖本次实际扫描到的文件，保留未扫描文件的旧索引，避免静默丢失搜索来源。

点击“更新索引”只重建项目文件来源；手动记录和已收录的网页不会被删除。

### 手动记录

点击“新建记录”，保存真正需要复用的结论。推荐写明：

1. 问题或决策的结论。
2. 原因、约束和涉及的文件。
3. 复现或验证步骤。
4. 尚未验证的风险或后续工作。

这样搜索到记录时，仍能回到源代码或原始文档验证，而不是把知识库当成不可追溯的答案集合。

### 网页文档集

在选中项目后点击“收录网页”，填写文档集名称和入口 URL。

- 名称不能为空，最多 20 个字符；URL 只支持 HTTP 或 HTTPS。
- 从入口页开始，只跟随同域、与入口同级路径或其子路径的链接；同一主机的 HTTP → HTTPS 升级重定向会被视为同一入口范围。
- 最多向下跟随 3 跳，单次最多收录 50 页，单页内容最多 2 MiB；重定向最多 5 次，待抓取链接队列最多保留 500 个。
- 每页会保存标题、正文、原始 URL 和抓取时间；搜索结果会展示所属文档集名称。
- 同一项目再次收录相同入口 URL，会更新该文档集的旧页面，而不是重复新增。

首版面向公开、静态 HTML 或纯文本页面；需要登录、由 JavaScript 在浏览器运行后才生成正文的页面，可能无法得到可用内容。它不会自动爬完整网站。

### 关系图谱

选中项目后点击“关系图谱”，可以查看已有知识的来源层级：项目直接连接本地文件和手动记录；网页条目会先连接到所属网页文档集，再连接到项目。

- 图谱不保存额外副本、不新增数据库表，也不会进行全库扫描；只有打开图谱时才按需读取当前项目。
- 为保证窗口保持流畅，最多展示最近更新的 120 条知识；界面会明确显示当前展示数量和项目总条目数。
- 点击节点或使用 Tab、Enter/空格，可以查看条目类型和原始文件路径或 URL。图谱用于理解来源关系，实际修改前仍应在搜索结果中查看原始上下文。

## 数据与同步边界

sanKnow 数据保存在本地 SQLite：

- `knowledge_projects`：已添加的项目。
- `knowledge_entries`：项目文件、手动记录与网页页面。
- `knowledge_web_collections`：网页文档集名称、入口 URL 和最近抓取时间。

网页页面通过 `source_url` 和 `source_collection_id` 保持可追溯来源。它们没有加入 sanIP 现有的云同步触发器；项目代码和网页正文不会因 sanKnow 自动上传。

应用配置了统一根目录时，实际数据库会位于 `{统一根目录}/data/database.sqlite`；未配置时使用应用默认数据目录。数据库初始化会在迁移前保留最近三份备份。

## 数据库迁移与启动排查

网页文档集使用数据库 schema v6。旧 v5 数据库启动时必须先完成 v6 迁移：添加网页来源字段，再创建依赖这些字段的索引。初始建表 SQL 不应抢先创建这些索引，否则旧数据库会在启动时失败。

如果开发版启动日志出现 `knowledge_web_collections`、`at offset` 或 `sanomni.exe ... exit code: 101`：

1. 更新到包含 v6 迁移修复的代码并重启。
2. 不要删除或手动重建 `database.sqlite`。
3. 若仍失败，保留完整 Rust 错误日志，并检查 `settings.db_version` 与自动创建的数据库备份。

详细恢复步骤见 [故障排除](../dev/TROUBLESHOOTING.md)。

## 验收步骤

1. 在 Windows 的项目根目录运行 `pnpm tauri:dev`。
2. 打开 sanKnow，添加一个项目并确认能搜索到项目文件。
3. 点击“收录网页”，使用公开文档 URL，例如文档站的 `/docs/` 入口。
4. 确认提示收录页数，切换“网页”筛选并搜索网页内容。
5. 重新收录同一入口 URL，确认网页条目更新且没有重复页面。
6. 点击“关系图谱”，确认项目文件直接连到项目，网页条目通过所属文档集连接；条目超过 120 时确认提示展示上限。
