# IP 表情包管理 (IP Emoji & Sticker Pack Management)

## 概述

sanIP 资产管理域下的**表情包管理**（Sticker & Emoji Management）是针对 IP 形象表情包资产进行整理、分组、排序、快捷词配置及平台发布对接的核心业务模块。

---

## 核心交互与界面设计

### 1. 结构布局
- **左侧：表情包分组列表**
  - **全部表情**：汇总当前 IP 形象下的全部表情图片。
  - **未分组表情**：尚未归入具体套件的零散表情。
  - **套件列表**：已创建的表情包套件（如“日常表情第一弹”），点击可切换套件视图；支持新建与编辑套件基本信息与平台配套资产（图标、封面、横幅、赞赏图等）。
- **中间：表情网格与管理画布**
  - **顶部套件头信息**：展示套件名称、设定描述及“编辑”、“平台信息”展开按钮。
  - **常驻批量操作栏 (Batch Toolbar)**：
    - **全选 / 取消全选**：一键切换当前展示分组的所有表情选择状态。
    - **已选计数器**：实时显示已选中的表情数量，支持一键清空选中。
    - **批量更换分组**：快速将已选表情移动至其他套件或“未分组”。
    - **批量彻底删除**：对已选表情进行彻底删除确认。
    - *注：该操作栏常驻显示，当未选择任何项目时批量按钮自动置灰，杜绝卡片选择时页面高度跳动（Layout Shift）。*
- **右侧：平台信息栏（可折叠）**
  - 管理表情包在微信表情开放平台等各发布平台的上架状态、上架名称、尺寸规范及下载统计。

---

### 2. 表情卡片交互规范

每个表情卡片具备以下交互特性：

#### ① 独立拖拽排序手柄 (Dedicated Drag Handle)
- **手柄位置**：卡片右上角 `GripVertical` 图标（鼠标悬浮卡片时显现）。
- **安全防误触**：拖拽排序监听器严格限制于手柄区域。
- **优势**：直接点击图片查看大图、勾选左上角复选框、点击操作按钮或点击底部快捷词输入框时，不会触发拖动判定，交互精准流畅。

#### ② 左上角快捷复选框 (Selection Checkbox)
- 鼠标悬浮或已被选中时高亮显示。
- 点击直接切换选中状态，联动顶部常驻批量操作栏。

#### ③ 居中两行悬浮操作栏 (Two-Row Action Overlay)
鼠标悬浮表情图片时呈现毛玻璃遮罩，操作按钮采用两行对称布局（每行 3 个图标）：
- **第一行 (基础查看与复制)**：
  - 👁️ **查看大图** (`Eye`)：进入沉浸式画廊大图预览模式。
  - 📂 **在文件夹中显示** (`FolderOpen`)：快速打开本地操作系统文件目录并定位文件。
  - 📋 **复制图片** (`Copy`)：将表情图自动转换为 PNG 并复制到系统剪贴板，支持直接在微信等聊天软件中粘贴。
- **第二行 (资产与分组管理)**：
  - 📥 **更换分组** (`FolderInput`)：弹出下拉菜单，单张快速切换所属表情套件。
  - ↩️ **退回普通图片** (`Undo2`)：将该表情退回普通 IP 资产库（保留源图片）。
  - 🗑️ **彻底删除** (`Trash2`)：从表情库与磁盘物理彻底删除。

#### ④ 触发词 / 快捷词与一键复制 (Trigger Word & Copy)
- **快捷词编辑**：卡片底部文本框支持随时为表情指定触发词（如“来消息了”、“开心”、“晚安”等），失去焦点自动保存。
- **一键复制快捷词**：当配置了快捷词时，输入框右侧提供 `Copy` 复制按钮（悬浮时显现），点击即可将快捷词文本复制至剪贴板，并伴随 Toast 反馈。

## 数据持久化与 API

- **排序存储**：前端拖拽完成后调用 `ipApi.updateEmojisSort(ids)`，实时更新 SQLite 数据库中的表情顺序。
- **快捷词更新**：文本框失焦调用 `ipApi.updateEmojiTriggerWord(emojiId, word)`。
- **分组迁移**：调用 `ipApi.moveEmojisToPack(emojiIds, packId)` 批量变更表情归属。
